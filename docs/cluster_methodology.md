# 集群方法论

本项目使用固定31个主题/指数集群作为展示与聚合维度。每只ETF最多只有一个
`primary_cluster`，其他匹配概念只进入`secondary_tags`，不参与资金重复聚合。

分类优先级：

1. 跟踪指数代码；
2. 跟踪指数官方名称；
3. ETF扩位简称；
4. ETF简称。

同义合并：

- 证券ETF和券商ETF合并为券商/证券；
- 芯片ETF和半导体ETF合并为半导体/芯片；
- 电池ETF和储能ETF合并为电池/储能。

资金口径：

- 成交额表示二级市场换手、活跃度和分歧；
- 估算净申购/赎回 = 份额变化 * 单位净值；
- 不同ETF的原始份额不能直接相加，只能先折算成金额再聚合。
