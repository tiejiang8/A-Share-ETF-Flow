# ETF权威回退源清单

更新时间：2026-07-02

## 第一性原则

- ETF二级市场行情、上市份额和交易所披露的ETF规模，仍以交易所官方数据为第一优先级。
- 证监会基金电子披露网站、巨潮资讯网、基金公司官网属于权威披露源，但字段边界不同；只能补它们正式披露的字段。
- 成交额不能从公告源推导；份额变化也不能用净值、公告标题或第三方估算替代。

## Playwright复测结论

- `http://eid.csrc.gov.cn/fund`：Playwright 状态 `200`，可访问“净值信息/公告信息/主体信息”。
- `https://eid.csrc.gov.cn/fund`：当前环境返回 `ERR_SSL_PROTOCOL_ERROR`；因此项目使用 HTTP 官方入口。
- `https://www.cninfo.com.cn/`：Playwright 状态 `200`，可访问基金/公告门户。
- `https://www.chinaamc.com/jgb/zszq/etfssqd/`：Playwright 状态 `200`，并暴露基金公司ETF列表JSON接口。
- `https://www.sse.com.cn/disclosure/fund/etflist/`：Playwright 状态 `200`，可访问ETF公告申购赎回清单。
